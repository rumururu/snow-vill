# Snow Village — Flutter app (iOS / Android)

Companion app to the web (https://snow.mkideabox.com). Same backend (shared `mkideabox-games` Supabase, prefix `snowvill_`), same art and scene geometry, so villages are shared between web and app. Purpose: a full village experience in the stores plus **store billing** (decorating packs via RevenueCat — next phase).

Bundle id: `com.mkideabox.snowvillage` · Store accounts: same as other mkideabox apps (`~/.claude/PROJECTS.md`).

## Run
1. `cp env.example.json env/dev.json` and fill `SUPABASE_ANON_KEY` (anon key only; see the repo README "Backend (M1)").
2. `flutter pub get`
3. Device testing per the global rules: `frun acquire --os android --form phone` — `.frun` passes `--dart-define-from-file=env/dev.json` to the launched app. Release builds must pass the same define file.

Checks: `dart analyze` · `flutter test` (geometry parity with the web, validation, invite-link parsing, API mapping).

## Layout
- `lib/data/` models, validation (same limits as web/server), `remote_api.dart` (anon RPC + `snowvill-photo` Edge Function), device identity (install id + ownership secrets in shared_preferences), photo prep (1:1 crop, 512px JPEG, EXIF dropped)
- `lib/scene/` port of `src/lib/scene.ts`: reads `assets/art/asset-geometry.json`; taps resolve to the front-most house silhouette
- `lib/screens/` home (my villages, create, open invite link), create, village (scene, claim, photo frame, invite, owner delete)
- `lib/l10n/` ARB (ko template, en)
- `assets/art/` generated by `python3 ../scripts/build_assets.py` — do not edit by hand

Standards deviation: Riverpod without `riverpod_generator` (the generator does not resolve with Flutter 3.41 + current deps); manual `Notifier`/`AsyncNotifier` providers.
